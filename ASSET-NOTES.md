# Asset notes

This folder contains the artwork used by the GitHub profile README. The visual theme, layout, color palette, typography, supplied portraits, and animation structure have been retained. Only selected visible copy and the profile README content were revised.

- SVG artwork embeds its image/font resources to avoid external asset requests. Embedded portrait copies were palette-optimized to reduce the size of the image-heavy SVG files; the original transparent PNG files in `assets/` remain unchanged.
- SVG animation may render differently across GitHub and other viewers; the static text/artwork remains the fallback.
- The profile README uses ordinary Markdown links for clickable GitHub and LinkedIn destinations.
- No unverified profile metrics are displayed.
- Font licensing information is in `FONT-LICENSES.md`.
