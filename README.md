## How I approach a project

1. **Understand the question** — define the problem and what the data needs to answer.
2. **Prepare the data** — inspect data types, missing values, duplicates, and quality issues.
3. **Analyze and visualize** — use suitable queries, summaries, and charts to identify patterns.
4. **Communicate the result** — explain findings clearly and document assumptions and limitations.
